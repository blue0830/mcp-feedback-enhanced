# 遠端溝通指南（Discord）

`feedback-cli` 可以把每一次回饋請求同步發到你自己的 Discord 私人論壇頻道，讓你在手機上也能回覆。允許的使用者在貼文裡發出的第一則可用文字回覆，效果和在本機視窗提交一樣，會直接結束這次 CLI 呼叫。本機視窗仍會照常彈出，誰先答就聽誰的。

此功能**預設關閉**，只對 `feedback-cli` 生效（MCP 伺服器開啟的視窗裡不會出現這項設定）。

## 🧭 運作方式

- 一次 `feedback-cli` 呼叫對應一則論壇貼文。貼文標題是 `[專案目錄名] 摘要首行 (#短ID)`；第一則訊息包含摘要、專案目錄、截止時間和回覆說明，並 @ 允許的使用者，手機會收到推播。
- 允許的使用者在該貼文裡發的**第一則可用文字訊息**就是最終答覆，機器人會立刻回一則「已收到」。文字附件也算（Discord 會把超長文字自動轉成 `message.txt`）；圖片和其他檔案會被忽略。
- 如果你先在本機視窗答覆，貼文會標記為「本機已答覆」並封存。
- 回覆是透過每 3 秒左右的 HTTPS 輪詢取得，不使用 Gateway 長連線，也沒有常駐背景程序。
- 本機視窗頂部會顯示遠端狀態（未啟用 / 連線中 / 等待回覆 / 無法使用 / 已在遠端答覆 / 已在本機答覆），點擊即可開啟遠端設定。

## 🛠️ 設定步驟

### 1. 建立機器人

1. 開啟 [Discord Developer Portal](https://discord.com/developers/applications)，建立一個 **New Application**。
2. 在 **Bot** 頁面點擊 **Reset Token**，複製 Token（只會顯示一次）。
3. 同一頁面把 **Privileged Gateway Intents** 裡的 **Message Content Intent** 打開。沒開的話，Discord 回傳的訊息文字是空的，回覆無法讀取。

### 2. 準備私人伺服器和論壇頻道

1. 使用你信任的私人伺服器：摘要和回覆都會保存在 Discord 上。
2. 建立一個**論壇（Forum）**頻道。如果論壇要求發文必須選標籤，請至少建立一個標籤（機器人會使用第一個）。
3. 開啟**開發者模式**（Discord 使用者設定 → 進階）。
4. 對論壇頻道按右鍵 → **複製頻道 ID**；對你自己的名字按右鍵 → **複製使用者 ID**。

### 3. 邀請機器人

1. 在 Developer Portal 開啟 **OAuth2 → URL Generator**，勾選 scope `bot`，並授予以下權限：
   - 檢視頻道（View Channels）
   - 傳送訊息（Send Messages，在論壇裡對應「建立貼文」）
   - 在貼文中傳送訊息（Send Messages in Threads，對應「在貼文中傳送訊息」）
   - 嵌入連結（Embed Links）
   - 附加檔案（Attach Files，過長的摘要會以 `summary.md` 附件傳送）
   - 讀取訊息歷史（Read Message History）
   - 管理貼文（Manage Threads，用來把處理完的貼文封存）
2. 開啟產生的連結，把機器人加入你的私人伺服器。注意不要讓某個頻道的專屬權限把論壇頻道對機器人隱藏。

只有「管理貼文」是可選的：沒有它也能正常使用，只是處理完的貼文不會被及時封存，要等 Discord 在 24 小時後自動封存。

### 4. 設定並測試

```bash
feedback-cli --remote-settings
```

這會開啟一個只包含「遠端溝通」卡片的視窗：不會產生回饋請求，除了連線測試之外也不會向 Discord 傳送任何內容。請自己在前台終端機裡執行，它**只供人工使用，不要讓 Agent 呼叫**。設定完成後關閉視窗即可（如果退回到了瀏覽器，則按 Ctrl+C，或等 `--timeout` 到期）。同樣的卡片也在一般 `feedback-cli` 視窗的設定頁裡。

1. 填寫 **Bot Token**、**論壇頻道 ID** 和 **允許回覆的使用者 ID**（填你自己的使用者 ID；多個 ID 用逗號或空格分隔）。
2. 點擊 **測試連線**（尚未儲存的修改會先自動儲存）。論壇裡會出現一則測試貼文：請在 120 秒內在貼文裡回覆任意文字。
3. 所有步驟都通過後，打開 **啟用遠端溝通** 開關。

修改 Token、頻道或允許的使用者後，驗證結果會失效，功能自動關閉，需要重新測試通過後才能再次啟用。Token 只寫不讀：儲存後不會再顯示，留空表示保持原本的 Token。

## 🌐 網路需求

- 只需要本機主動發起 HTTPS 對外連線：`discord.com`（API）、`cdn.discordapp.com` 和 `media.discordapp.net`（下載文字附件）。
- 不需要公網 IP，不監聽任何連接埠，也沒有 IP 或監聽位址的設定項。
- 如果本機需要代理或出口節點（例如 Tailscale 出口節點），請在系統層面設定。標準的代理環境變數（`HTTPS_PROXY`、`HTTP_PROXY`、`NO_PROXY`）會被沿用。

## ⚠️ 使用限制

- Agent 所在工具的外層逾時和 `feedback-cli` 自身的逾時（預設 3600 秒）仍然有效；電腦休眠或關機時也收不到回覆。CLI 被強制終止後貼文會一直保持開啟，第一則訊息裡的「最後存活時間」會停止更新。
- 只支援文字回覆。文字附件總大小不超過 256 KiB，且必須是 UTF-8。
- 只有允許的使用者的回覆才算數。回覆會變成 Agent 收到的指令，所以請使用私人伺服器，並讓允許名單盡量短。
- 遠端設定只能透過迴路位址（`127.0.0.1`、`localhost` 或 `[::1]`）修改，例如經 SSH 轉發的 `localhost` 連接埠。透過其他位址開啟的視窗（例如 `MCP_WEB_HOST=0.0.0.0` 後用區域網路 IP 存取）無法修改。
- Token 以明文儲存在 `~/.config/mcp-feedback-enhanced/remote_channel.json`（POSIX 下僅擁有者可讀寫）。想徹底關閉，可以在卡片裡關掉開關或直接刪除該檔案；要換存放位置，可設定環境變數 `MCP_FEEDBACK_REMOTE_CONFIG`。

## 🩺 常見問題

| 卡片上的提示 | 處理方式 |
|---|---|
| 讀不到訊息文字 | 打開 Message Content Intent（步驟 1） |
| 找不到該頻道 | 檢查頻道 ID，以及機器人是否已加入伺服器 |
| 該頻道不是論壇頻道 | 換成論壇（Forum）頻道 |
| 機器人缺少權限 | 依步驟 3 給機器人在該頻道授予權限 |
| Token 無效或已被撤銷 | 在 Developer Portal 重設 Token 後重新填寫 |
| 網路不通 | 檢查代理或出口節點 |
| 該論壇要求發文必須選標籤 | 在論壇裡至少建立一個標籤 |
